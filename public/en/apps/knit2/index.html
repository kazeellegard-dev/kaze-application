FEATURES

Key features

Easy row and stitch counting

Tap the “Row” and “Stitch” buttons to count. Choose to count by 1, 2, 5 or 10.

Saved for each project

Counts are saved per project, and the project list shows how all your projects are coming along at a glance.

See your progress

Set the total number of rows to see your progress. Rows can advance automatically at a set stitch count, and you can use extra counters too.

Images and notes at hand

Keep a pattern image or a note on screen while you count. Move and resize it freely with the handles.

Make it your own

Use your own image for the count button, and adjust how deep the background color is.

Comfortable while you knit

Turn sound effects on or off, and keep the screen from dimming while you knit.

HOW TO USE

How to use

The basic flow. More detailed instructions will be added over time.

  1. Add a project

    Tap “＋” in the project list, then choose a name and an image and save.

  2. Count

    Open the project and tap the “Row” and “Stitch” buttons to count.

  3. Check your progress

    Set the total number of rows to see your progress, also shown in the project list.
