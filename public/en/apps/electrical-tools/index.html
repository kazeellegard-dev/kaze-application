FEATURES

Key features

Voltage divider

From an input voltage and a target voltage, find resistor combinations close to the target in the E6/E12/E24/E48 standard series. See the minimum, typical and maximum output voltage with resistor tolerance taken into account.

RC transient response

Calculate the time constant τ = RC from resistance and capacitance. See the rise and fall as a graph, and check the voltage at any elapsed time with the slider.

Combined resistance

Supports series and parallel connections. Calculates the nominal, minimum and maximum combined resistance from several resistances and their tolerances.

LCR filter

Calculate filter characteristics from R, L and C values. Check the time constant and cutoff frequency, with the frequency response shown as a graph.

HOW TO USE

How to use

The basic flow.

  1. Choose a calculation

    Pick “Divider”, “Transient”, “Resistance” or “LCR filter” from the tabs at the bottom.

  2. Enter values

    Enter values such as voltage, resistance and capacitance.

  3. Check the result

    The results and graphs appear right away.
