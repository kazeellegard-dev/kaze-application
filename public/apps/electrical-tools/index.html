FEATURES

主な機能

分圧抵抗値算出

入力電圧と目標電圧から、E6/E12/E24/E48の標準抵抗系列で目標に近い抵抗の組み合わせを検索。許容差を考慮した出力電圧の最小・標準・最大値も確認できます。

RC過渡応答

抵抗値とコンデンサ容量から時定数 τ＝RC を計算。立ち上がり・立ち下がりをグラフで確認し、任意の経過時間の電圧もスライダーで確認できます。

合成抵抗値算出

抵抗の直列・並列に対応。複数の抵抗値と許容差から、合成抵抗の公称値・最小値・最大値を計算します。

LCRフィルタ算出

R・L・Cの値からフィルタの特性を計算。時定数とカットオフ周波数を確認でき、周波数特性はグラフで表示されます。

USE CASES

こんな場面に

複雑なシミュレーションをするほどではない、日常的な確認作業をサポートします。

  • 回路設計中の値の確認
  • 抵抗・コンデンサの定数検討
  • 電源回路の分圧設計
  • RC回路の遅延時間確認
  • 抵抗の直列・並列の組み合わせ検討
  • フィルタのカットオフ周波数確認
  • 試作・デバッグ時の簡易計算
  • 電子工作や回路の学習

HOW TO USE

使い方

基本の流れです。

  1. 計算の種類を選ぶ

    画面下のタブから「分圧抵抗」「過渡応答」「合成抵抗」「LCRフィルタ」を選びます。

  2. 値を入力する

    電圧や抵抗値、容量などの値を入力します。

  3. 結果を確認する

    計算結果とグラフがその場で表示されます。
